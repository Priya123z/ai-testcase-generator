How it works

      

        

          
The model answers in JSON

          

            Groq's json_object mode means there are no markdown fences to scrape.
            The prompt carries the schema, and openai/gpt-oss-120b fills it in.
          

        

        

          
Then it gets validated

          

            Every field is checked before you see it — step keywords must be real Gherkin,
            test names must be snake_case. Almost-right JSON fails here rather than becoming
            a .feature file that will not parse.
          

        

        

          
With no key, you get a real answer
          

          

            Saved from an actual run and labelled as saved. The page never shows you a broken
            widget, and it costs nothing to keep running.
